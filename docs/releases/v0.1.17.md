## macOS joins the desktop technical preview

- First experimental macOS download for Apple Silicon Macs (M1 or newer), alongside Windows and experimental Linux downloads.
- Mac folder selection opens SD cards in place. Automatic scanning checks mounted volumes under `/Volumes` and excludes macOS system-volume false matches.
- Applying core changes now shows an activity indicator, file counts, and status messages for backups, writes, removals, cleanup, and the final inventory refresh. Keep the card connected and the app open until it finishes.

Game Shelf is not included in this release.

## Downloads

- **Windows x64 · unsigned technical preview:** extract the Windows ZIP into a new folder and launch `EzPocket.exe`. Keep all included files together. No separate runtime installer is required. Windows may show a SmartScreen warning or organization policy may block it.
- **macOS Apple Silicon · experimental · unsigned:** extract the `macos-arm64-unsigned.zip`, read the included `READ-ME.md`, and move `EzPocket.app` to Applications. No separate .NET installation is required. Intel Macs are not supported. A SHA-256 checksum is attached beside the ZIP.
- **Linux x64 · experimental:** requires GTK 4.12+ and its introspection typelib. Extract the Linux archive and run `./EzPocket.Linux`. Desktop and device testing remain in progress.

Mac and Linux assets are attached after their packaging jobs finish, so they may appear shortly after the Windows download.

## First launch on macOS

This preview has no Apple Developer ID signature and is not notarized. A local ad-hoc signature requires no Apple certificate installation.

Attempt to open the app once. If macOS blocks it, dismiss the warning, open **System Settings → Privacy & Security**, scroll to the EzPocket message, choose **Open Anyway**, and confirm **Open**. This was required during the first Mac test. Managed Macs may prohibit this exception. Do not disable Gatekeeper system-wide.

Mac launch and core updates have received initial manual testing. Firmware, Save Vault restore, and native plugin compatibility still need broader Mac validation. All downloads remain early technical previews.

Keep a separate backup of important SD-card content, review changes before writing, and safely eject the card afterward.
