## Palette Studio

Open **PALETTE STUDIO** from the dashboard or Asset Library to browse, edit, and compare Game Boy palettes.

- Browse starter swatches, installed palettes, and local `.gbp` / `.pal` files. With a target selected, browse the community palette pack without installing it.
- Choose colors with the native Windows picker or edit RGB hex values. APGB background, sprite, and window groups can be edited separately; other groups and the LCD-off color are preserved.
- Compare palettes with a generated calibration pattern or your own screenshot, processed locally. Preview approximates four brightness shades; it does not identify hardware layers or emulate a game.
- Keep local favorites, reverse colors, reset edits, and export in the source format. Export never overwrites an existing file.
- Choose **REVIEW INSTALL** to inspect changes through the existing asset workflow. Only its separate Apply action writes to the selected target; export to that target is blocked.

Editing and local export work without a connected Pocket. The existing web editor remains available. No game images are bundled.

## Downloads

- **Windows x64:** extract the preview ZIP into a new folder and launch `EzPocket.exe`. Keep all included files together. The .NET and Windows App SDK runtimes are included. This preview is unsigned; Windows may show a SmartScreen warning or organization policy may block it.
- **Linux x64:** the experimental archive is attached after Linux packaging and startup validation pass. It requires GTK 4.12+ and the corresponding introspection typelib. Extract the archive and run `./EzPocket.Linux`. Palette Studio desktop and device behavior still need manual testing on Linux.
- **macOS:** no downloadable build yet.

Keep a separate backup of important SD-card content, review changes before writing, and safely eject the card afterward.
