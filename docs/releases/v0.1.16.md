## Clearer dropdowns and a quieter dashboard

- Dropdowns across Core Inventory, Quick Start, Palette Studio, and Pocket Plugins now share a crisp outline, consistent sizing, and hover, focus, and disabled feedback. Native selection and keyboard behavior are preserved.
- Pocket Plugins is now in the quieter TOOLS row near the bottom of the dashboard.
- The project landing page has simpler copy.

Game Shelf is not included in this release.

## Downloads

- **Windows x64:** extract the preview ZIP into a new folder and launch `EzPocket.exe`. Keep all included files together. No separate runtime installer is required. This preview is unsigned; Windows may show a SmartScreen warning or organization policy may block it.
- **Linux x64:** the experimental archive is attached after Linux packaging and startup checks pass. Requires GTK 4.12+ and its introspection typelib. Extract and run `./EzPocket.Linux`. Desktop and device testing remain in progress.
- **macOS:** no downloadable build yet.

Keep a separate backup of important SD-card content, review changes before writing, and safely eject the card afterward.
