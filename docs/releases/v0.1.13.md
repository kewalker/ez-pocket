## Quick Start, whenever you need it

Open **QUICK START** from the dashboard for an optional guide to connecting your Pocket storage, understanding the scan, choosing cores or a starter collection, and reviewing changes.

- Opens only when you choose it. There is no mandatory first-launch tour.
- Scan connected storage or choose a folder, then see the installed-core count, recognized Pocket folders, and available space.
- Continue into the existing core inventory or add a curated collection to your selection. Installed cores are kept selected.
- Review the guide's explanation of additions, replacements, removals, and the separate Apply action.
- Leave through the in-page Back action. Scan results that finish after leaving the guide are ignored.

The guide does not install cores or change files on the target. Device writes still require the existing review and explicit approval.

## Downloads

Linux uses an updated GTK backend to fix a crash when returning from core review to the inventory. Release publishing now requires the Linux resize and navigation checks to pass, in addition to Windows validation.

- **Windows x64:** extract the preview ZIP into a new folder and launch `EzPocket.exe`. Keep all included files together. The .NET and Windows App SDK runtimes are included. This preview is unsigned; Windows may show a SmartScreen warning or organization policy may block it.
- **Linux x64:** the experimental archive is attached after the Linux release job passes. It requires GTK 4.12+ and the corresponding introspection typelib. Extract the archive and run `./EzPocket.Linux`. Desktop and device testing remain in progress.
- **macOS:** no downloadable build yet.

Keep a separate backup of important SD-card content, review changes before writing, and safely eject the card afterward.
