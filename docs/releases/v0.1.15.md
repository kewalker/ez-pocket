## Pocket Plugins (initial support)

Install and manually run core setup tools and file generators using the Pocket Plugin format shared by Pocket Sync and pupdate.

- Open **POCKET PLUGINS** on the dashboard and install from a GitHub repository whose latest release includes `plugin.json` and `plugin.wasm`.
- Review the plugin's source, version, and allowed network hosts before running. Installation does not execute a plugin; browser links require a click.
- Runs use a full local working copy of the Pocket target. Review additions, replacements, and deletions before choosing **APPLY CHANGES**. Replaced and deleted files are backed up; failed applies attempt recovery.
- Saves, Memories, and root firmware files are protected. There is no automatic execution, automatic updating, or plugin catalog.

This initial version supports working copies up to 64 GiB / 200,000 files and requires local space for the copy, generated output, and backups. Plugins can read their working copy and send data to their listed hosts; run only trusted plugins. Windows x64 runtime tests exercise prompts, logs, browser links, and cancellation. Linux plugin behavior still needs desktop testing.

## Downloads

- **Windows x64:** extract the preview ZIP into a new folder and launch `EzPocket.exe`. Keep all included files together. No separate runtime installer is required. The preview is unsigned; Windows may show a SmartScreen warning or organization policy may block it.
- **Linux x64:** the experimental archive is attached after Linux packaging and startup checks pass. Requires GTK 4.12+ and its introspection typelib. Extract and run `./EzPocket.Linux`.
- **macOS:** no downloadable build yet.

Keep a separate backup of important SD-card content, review changes before writing, and safely eject the card afterward.
