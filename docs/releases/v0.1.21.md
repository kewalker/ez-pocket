## Core readiness, card cleanup, and safe eject

- **Core readiness** shows which installed cores are missing a file they load by themselves, such as a BIOS. It names the exact file and folder, and flags files that are in the wrong folder or the wrong size. Checks follow each core's own `data.json`; ez-pocket never supplies BIOS or game files. Open it from **CORE READINESS** on the dashboard or from a Pocket health finding. Arcade games defined by instance JSON files are not checked yet.
- **Card cleanup** finds hidden macOS files (`._*` and `.DS_Store`) that show up as clutter in Pocket menus. Review the list, then choose **REMOVE SELECTED**; each file is checked again before removal. The card's macOS Trash is opt-in. Leftover asset folders from removed cores are listed but never deleted, because they may hold your games or BIOS files.
- **EJECT CARD** safely ejects a removable card from the dashboard or after cleanup. If another app is using the card, ez-pocket says so instead of ejecting.
- Pocket health now includes required core files.
- Fixed: on Windows, a folder chosen with **CHANGE TARGET** could be ignored, and a folder-picker failure could close the app.

Windows, Apple Silicon macOS, and Linux downloads remain unsigned or experimental technical previews. Keep a separate backup of important SD-card content and review changes before writing.
