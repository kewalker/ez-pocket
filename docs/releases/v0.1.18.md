## Lighter startup and checks when you request them

- Firmware checks now run only after choosing **CHECK FIRMWARE** on the firmware page. Launching the app, scanning a target, and returning to the dashboard no longer check firmware automatically.
- Startup restores saved target details and checks folder availability in the background. Use **RESCAN** to refresh inventory; the dashboard shows when the last scan ran.
- **CHECK HEALTH** runs its read-only inspection in the background with an activity indicator and a **CHECK AGAIN** action. Returning to the dashboard shows the last result for this session without repeating the inspection.
- Target scans and folder scans run in the background. Core management refreshes the installed inventory before comparing it with the live catalog.
- Existing validation before applying reviewed writes remains in place. No device writes happen during startup or scanning.

On the first launch after upgrading, previously selected targets may show no saved inventory yet. Choose **RESCAN** to populate their details.

Game Shelf is not included in this release.

Windows, Apple Silicon macOS, and Linux downloads remain unsigned or experimental technical previews. Keep a separate backup of important SD-card content, review changes before writing, and safely eject the card afterward.
