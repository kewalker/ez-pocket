## Direct plugin access and desktop polish

- Pocket Plugins now run directly against the explicitly selected target using the standard desktop runtime. Review the plugin source, version, and network access before running it.
- Direct plugin runs do not make a full-card copy, preview changes, create an automatic backup, or roll back completed writes. Plugins may modify saves, Memories, firmware, and other target files. Cancellation stops further execution but does not undo completed writes.
- Plugin prompts use selectable radio options, keep the active question visible, and show the direct-target warning in the page UI.
- Core sync preparation and apply failures now show friendlier in-page guidance while retaining technical details for diagnostics.
- Windows dropdowns use native placeholder rendering so selected values are not clipped by an extra header.
- Archived XAML under `artifacts/` is excluded from MAUI compilation, keeping clean Windows builds reliable.
- Game Shelf remains stashed and is not included in this release.

Windows, Apple Silicon macOS, and Linux downloads remain unsigned or experimental technical previews. Keep a separate backup of important SD-card content, review changes before writing, and safely eject the card afterward.
