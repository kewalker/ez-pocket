## Faster plugin runs and clearer choices

- **RUN PLUGIN** now runs trusted plugins directly on the selected Pocket target using the standard desktop runtime. It no longer copies or hashes the whole card before starting, removing the full-card preparation delay and local working-copy size limits.
- Plugin questions show their choices directly on the page. **CONTINUE** becomes available after selecting an answer, and the question scrolls into view.
- Fixed the shared Windows dropdown so its title no longer clips the selected plugin name. The selected name and expanded menu remain readable.

### Plugin behavior has changed

Choosing **RUN PLUGIN** gives that plugin direct read/write access to the target. Plugins can replace or delete any target files, including saves and firmware. There is **no staged change review, automatic backup, or rollback** for plugin runs. Cancellation stops further execution but does not undo completed writes. Run only plugins you trust, read their network access, and keep separate backups of important content.

Installing a plugin does not execute it. The application's own core, firmware, asset, and save-restore workflows retain their existing review and protection behavior.

Game Shelf and the experimental native overlay are not included in this release.

Windows, Apple Silicon macOS, and Linux downloads remain unsigned or experimental technical previews. Windows native plugin tests pass; Mac and Linux plugin/device behavior still needs platform smoke testing. Safely eject the card when finished.
